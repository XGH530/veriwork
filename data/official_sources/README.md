## 文件结构

- `raw/`：原始HTML页面，用于核查抓取内容。
- `text/`：去除脚本和导航后的正文文本。
- `manifest.json`：来源URL、发布日期、抓取时间、SHA-256和正文长度。
- `../../data/jurisdiction_policy_pack_v1.json`：将官方数值写入政策包，同时保留待核验字段。

## 使用边界

1. 人社部全国汇总可以证明数值来源，但不能替代地方通知中的适用城市和生效日期。
2. 广东最低工资分档对应地区必须查看官方附件，不能自行推断。
3. 社会保险缴费基数、办事指南和投诉流程仍需继续核验。
4. 正式答辩必须展示来源链接和抓取日期，不能只写“来自网络”。
