# 职安盾 VeriWork｜提交总清单

> 10月23日23:59:59只是全国系统最终截止时间。学校通常有更早的校内审核、公示和推荐截止时间，必须先向学校负责部门确认。

## A. 立刻完成：报名与资格

- [ ] 确定团队负责人：【请填写】
- [ ] 确定5名成员及学校：【请填写】
- [ ] 确定1至2名指导教师：【请填写】
- [ ] 确定第一申报单位：【请填写】
- [ ] 向学校确认校赛负责部门和内部截止时间
- [ ] 在 www.cmit.cn 完成注册和团队报名
- [ ] 选择：自主选题类—移动与网络应用开发类赛项
- [ ] 保存报名截图、系统通知和工作人员联系方式

## B. 本周完成：真实实验

- [ ] 使用 DeepSeek 运行至少两个模型对照
- [ ] 记录模型名称、版本、调用日期、提示词版本
- [ ] 运行80条开发集和40条冻结留出集
- [ ] 保存模型直答、普通RAG和职安盾混合链结果
- [ ] 记录失败请求、错误输出和人工修正情况
- [ ] 生成最新 `results/model_comparison_report` 和答辩图表

## C. 本周至下周：真实用户测试

- [ ] 招募不少于20名高校学生
- [ ] 测试前记录用户能否自行发现风险
- [ ] 测试中记录使用时间、操作卡点和理解偏差
- [ ] 测试后填写满意度、可信度和继续使用意愿问卷
- [ ] 让用户书面同意使用匿名反馈
- [ ] 不在公开材料中保留姓名、电话、学校账号或真实合同

## D. 下周完成：外部复核

- [ ] 邀请指导教师或法律实务人员抽样复核至少30个案例
- [ ] 记录复核范围和未覆盖范围
- [ ] 修改明显错误，保留修改日志
- [ ] 不把个人复核夸大为权威机构认证

## E. 下周完成：地方政策核验

- [ ] 核验北京、上海、广东官方政策
- [ ] 填写政策数值、适用地域、生效日期、来源链接和核验人
- [ ] 执行 `python tools/validate_policy_pack.py --strict`
- [ ] 未核验的数值不得进入正式风险结论

## F. 提交材料

- [ ] 作品介绍文档
- [ ] 可运行系统或访问说明
- [ ] 系统功能演示视频
- [ ] 界面截图
- [ ] 技术架构和测试说明
- [ ] 原创性与知识产权声明
- [ ] 人工智能工具使用情况说明
- [ ] 团队成员及指导教师信息
- [ ] 第三方素材、法源和代码来源清单
- [ ] 官网要求的其他附件

## G. 最终提交前检查

- [ ] 作品名称、成员、学校和指导教师无误
- [ ] 所有材料使用统一作品名称
- [ ] 视频可完整播放且无隐私信息
- [ ] 系统在没有外网时能够自动降级演示
- [ ] 所有指标均说明数据来源和限制
- [ ] 没有“保证法律正确”“替代律师”等夸大表述
- [ ] 至少提前24小时点击最终提交并取得作品编号
