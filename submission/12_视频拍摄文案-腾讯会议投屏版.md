# 职安盾 VeriWork 作品评审视频拍摄文案

> 目标：让不熟悉项目的人也能照着文案完成 3—5 分钟参赛视频。视频采用腾讯会议投屏 + 摄像头录制，展示真实系统操作。
>
> 视频要求：MP4、1920×1080、16:9、不超过 5 分钟、单个文件不超过 1GB；建议有解说配音和必要字幕；不得出现参赛学校、团队名称、成员姓名、指导教师、真实用户信息。

## 一、录制前 10 分钟准备

### 1. 电脑准备

- [ ] 使用 Chrome 或 Edge 浏览器打开：http://8.133.222.0/veriwork/
- [ ] 使用评审账号提前登录：`reviewer2026 / ReviewDemo!2026`
- [ ] 登录后停留在“工作台”，不要停在登录页
- [ ] 浏览器按 `F11` 全屏，隐藏书签栏、历史记录和个人信息
- [ ] 关闭微信、QQ、邮件、系统通知和弹窗
- [ ] 关闭其他无关标签页，只保留职安盾页面
- [ ] 浏览器缩放调整为 100% 或 110%，保证评委能看清文字

### 2. 演示材料准备

- [ ] 桌面准备合成聊天截图：`submission/demo/微信聊天截图_合成演示.png`
- [ ] 确认截图里没有真实姓名、手机号、身份证号
- [ ] 提前点击一次“高校毕业生三方协议”演示案例，确认能正常研判
- [ ] 提前测试一次聊天截图 OCR，确认能识别
- [ ] 提前测试一次“生成研判报告”和“证据链”
- [ ] 刷新页面，回到工作台，准备正式录制

### 3. 腾讯会议准备

1. 打开腾讯会议并登录。
2. 点击“快速会议” → “立即开会”。
3. 打开摄像头和麦克风，选择耳机麦克风，避免回音。
4. 点击“共享屏幕” → 选择“窗口” → 选择职安盾所在的 Chrome 窗口。
5. 点击“布局” → 选择“演讲者视图”或“画中画”，让摄像头显示在角落。
6. 点击“录制” → 选择“本地录制”。如果账号没有本地录制，使用云录制；仍不可用则用 Windows 自带录屏或 OBS 录制会议窗口。
7. 先录 10 秒测试，停止后回放，确认画面、声音、摄像头和共享屏幕都被录进去。
8. 确认无误后，开始正式录制。

> 注意：不要共享整个桌面，避免评委看到桌面文件、聊天窗口和个人信息。

### 4. 出镜准备

- [ ] 摄像头与眼睛平齐，光线从正面照过来
- [ ] 背景干净，不要出现学校、团队、个人信息
- [ ] 手机静音，电脑通知关闭
- [ ] 语速放慢，每句话之间停顿 1 秒
- [ ] 鼠标移动慢一点，操作后停 1—2 秒再说话

## 二、正式录制脚本（建议 4 分 45 秒—5 分钟）

### 0:00—0:20 开场（摄像头）

**画面：** 摄像头全屏或画中画，显示讲述人。

**口播：**

> 评委老师好，我是职安盾 VeriWork 项目演示。我们做的不是法律问答机器人，而是一套面向高校毕业生就业协议与合同的可验证风险研判平台。下面用五分钟演示它如何从一份材料走到可执行报告。

**屏幕文字：**

> 职安盾 VeriWork｜就业协议与合同可信研判

---

### 0:20—0:50 问题（共享屏幕，工作台）

**操作：** 切换到职安盾工作台，慢慢移动鼠标到“合同研判”和“待研判案例”。

**口播：**

> 毕业生常遇到三类材料：实习协议、三方协议、劳动合同。问题不是没有条款，而是看不懂、找不到依据、不知道怎么行动。通用大模型能回答，但可能引用错误，或者在信息不足时仍然给出确定结论。

---

### 0:50—1:20 方案总览（共享屏幕，工作台）

**操作：** 指向工作台的“核查流程”或“从发现风险到形成行动闭环”。

**口播：**

> 职安盾把过程拆成六步：材料识别、事实抽取、规则与法源、模型候选、人工复核、证据行动。规则负责硬约束，模型只在允许的风险 ID 内提出候选；没有原文或没有可靠法源时，系统会标记待核实，而不是强行给结论。

---

### 1:20—2:10 三方协议演示（共享屏幕）

**操作：**

1. 在工作台“待研判案例”中点击“高校毕业生三方协议”。
2. 等待系统自动研判完成。
3. 指向“基本事实”面板。
4. 慢慢向下滚动到风险清单。

**口播：**

> 先看三方协议。系统自动识别材料类型，即使之前选择的是劳动合同，也会根据正文纠正为三方协议。这里抽取甲方、学校、岗位、报到日期、试用期、月薪、违约金和档案户口安排。
>
> 风险清单里，系统发现以三方协议代替劳动合同、违约金依据不清、关键条款待定、档案户口安排不清等问题。每条风险都给出页码、原文、法源和行动建议。

**停顿：** 指向第一条高风险，停 2 秒。

---

### 2:10—2:50 微信聊天截图 OCR（共享屏幕）

**操作：**

1. 点击顶部“合同研判”。
2. 点击“清空”。
3. 把 `微信聊天截图_合成演示.png` 拖入“拖入文件，或从微信 / QQ 直接拖入聊天截图”区域。
4. 等待 OCR 识别完成，文本框出现聊天文字。
5. 点击“运行可信研判”。

**口播：**

> 第二份材料是微信聊天截图。评审老师可以看到，我们支持把微信、QQ 截图直接拖入，也支持 Ctrl+V 粘贴。服务端 OCR 识别后，文字进入文本框，用户可以先校对，再运行研判。
>
> 这份聊天记录里，HR 说三方协议先签、入职后不用再签劳动合同，还提到六个月试用期、两万元违约金、档案户口不接收。系统会把这些口语化表达转成可核查的风险点。

**等待：** 如果 OCR 还在识别，继续说：

> 识别结果不会直接作为最终结论，用户可以在文本框里修改错字，再运行可信研判。

---

### 2:50—3:30 报告与证据链（共享屏幕）

**操作：**

1. 研判完成后，指向风险清单。
2. 点击“生成研判报告”，查看 HTML 报告。
3. 指向“基本事实”“风险结论”“待核实事项”。
4. 关闭报告标签页，回到职安盾。
5. 点击“证据链”。

**口播：**

> 研判结果不是一句话，而是一份可复核的报告：基本事实、风险结论、页码和条款、原文、法源、待核实事项、原始文件 SHA-256 和后续行动。报告可以导出 HTML 或 PDF。
>
> 接着进入证据链，系统把风险转成证据清单、时间线和沟通问题，帮助用户知道保存什么、找谁沟通、怎么办理。

---

### 3:30—4:10 可信评测与技术架构（共享屏幕）

**操作：**

1. 点击“可信评测”。
2. 点击“运行回归评测”，等待结果出现。
3. 指向指标卡片。
4. 点击“系统说明”，展示“六层可信研判链”。

**口播：**

> 职安盾把可信性做成可测量的指标。系统保留开发集、冻结留出集和失败案例，区分开发结果与泛化结果。当前规则库有 29 类规则、19 条法源，覆盖劳动合同、实习协议、三方协议和劳务协议。
>
> 技术上，规则、结构化事实、法源检索、模型候选和校验器分工明确。大模型不能修改风险等级，也不能新增不存在的法条。

---

### 4:10—4:40 应用价值与边界（摄像头画中画）

**操作：** 停止滚动，切回摄像头画中画或演讲者视图。

**口播：**

> 这套系统可以用于高校就业指导中心的签约前自查、人社和工会的普法与材料整理，也可以用于企业实习和三方协议合规自查。
>
> 需要说明的是，系统用于风险提示、普法教育和材料整理，不替代律师、仲裁机构或人社部门的最终判断；涉及实际用工关系和地方标准的部分必须人工复核。

---

### 4:40—5:00 收尾（摄像头）

**画面：** 摄像头全屏或画中画。

**口播：**

> 职安盾的目标，是让每一条风险结论都有原文、有依据、有下一步；没有依据时，敢于说待核实。谢谢评委老师。

**屏幕文字：**

> 职安盾 VeriWork｜规则优先 · 模型辅助 · 人工复核

## 三、录制中的注意事项

- [ ] 不要展示登录密码、API Key、管理员后台、服务器信息
- [ ] 不要展示真实合同、真实姓名、手机号、身份证号
- [ ] 不要展示学校、团队、教师、个人社交账号
- [ ] 如果操作失误，停 3 秒，从本段开头重录，后期剪掉
- [ ] 鼠标不要快速乱晃，指向哪里就说到哪里
- [ ] 每完成一个操作，停 1—2 秒再继续
- [ ] 如果 OCR 或网络卡顿，保持解说，不要连续点击
- [ ] 建议录 2—3 遍，选最流畅的一遍

## 四、录制后检查

- [ ] 视频为 MP4
- [ ] 分辨率 1920×1080，16:9
- [ ] 时长不超过 5 分钟
- [ ] 文件不超过 1GB
- [ ] 有清晰解说配音
- [ ] 有必要的字幕或文字标注
- [ ] 画面、声音、字幕同步
- [ ] 没有学校、团队、教师、真实用户信息
- [ ] 没有密码、API Key、管理员后台
- [ ] 视频内容与 PPT、作品介绍文档和实际系统一致
- [ ] 导出 1080P，保存原始文件和压缩版各一份

## 五、腾讯会议录制失败时的备用方案

1. 使用 Windows 自带录屏：`Win + Alt + R`，选择录制腾讯会议窗口。
2. 使用 OBS：录制“窗口采集”+“摄像头”，麦克风选择耳机麦克风。
3. 使用剪映/CapCut：录屏后导入，补字幕、降噪、裁剪。
4. 如果网络不稳定：先录制本地系统操作，再用腾讯会议补录开场和结尾，后期拼接。

## 六、字幕与后期

- 建议用剪映/CapCut 的“识别字幕”自动生成，再人工校对。
- 字幕不要遮挡系统主体，字号适中。
- 不需要复杂片头、转场和背景音乐；评审重点是真实系统、创新和表达清楚。
- 导出设置：1080P、30fps、MP4、H.264。
