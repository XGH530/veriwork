# 职安盾 VeriWork｜三分钟现场演示脚本

## 0:00-0:20 项目定位

“各位评委，职安盾不是法律问答机器人。我们研究的核心问题是：在就业合同这种高风险场景里，通用大模型虽然能回答，但结论不可追溯、法条可能出错，也无法证明可靠性。所以，我们做了一套可验证的 AI 风险评估与证据链系统。”

## 0:20-0:45 展示工作台

打开工作台，指出四项核心能力：规则硬约束、法源可追溯、大模型语义解释、交叉验证与人工复核。

“每一条高风险结论都必须回答三个问题：合同原文是什么、依据是什么、用户下一步做什么。”

## 0:45-1:30 运行合同研判

点击“载入风险样例”，再点击“运行可信研判”。等待进度条完成后，指出：

- 风险分和高风险数量。
- 放弃社保、入职押金、培训贷、无偿加班、三年竞业限制等条款。
- 每条风险的严重等级、置信度和法源标签。

打开一条高风险风险卡，切换到“条款定位”。

“系统不仅识别关键词，还把结论绑定到原文，并对不确定的地方提示人工核验。”

## 1:30-2:00 展示可信轨迹

切换到“可信轨迹”：

1. 条款抽取识别多少个语义片段。
2. 法源检索命中多少条公开法源。
3. 规则引擎识别多少项高、中风险。
4. 校验器执行无依据拒答和人工复核策略。

“这里最重要的不是模型写了什么，而是模型不能修改硬规则，也不能新增不存在的法条。”

## 2:00-2:25 展示证据和行动闭环

点击“加入证据链”，展示：

- 证据完整度。
- 事件时间线。
- 与 HR 沟通的问题清单。
- 投诉与仲裁材料草稿。

“我们不把风险识别当成终点，而是继续把用户带到证据保存和行动办理。”

## 2:25-2:50 展示可信评测

进入“可信评测”，点击“运行回归评测”。展示：

- 风险召回率。
- 法源覆盖率。
- 无依据结论率。
- 平均处理时间。
- 通用模型直答和职安盾可信链路的对照结果。

说明：“当前是内置开发集回归演示，正式参赛前会替换为经匿名化和人工复核的盲测集。”

## 2:50-3:00 收束

“职安盾让 AI 在高后果场景中有依据、可验证、能行动。我们解决的不是多回答一个法律问题，而是让大模型在真正重要的场景里可以被信任。”
