# 异地备份启用说明

## 目标

服务器每天 03:30 生成数据库备份和证据目录压缩包；本机每天 04:30 拉取到 `D:\VeriWorkOffsiteBackups`，保留 30 天。

## 启用

在普通 PowerShell 中执行：

```powershell
cd "C:\Users\谁知青杉\Documents\Codex\2026-09-28\2026-2023-1-2-1-2026\outputs\职安盾-VeriWork"
powershell -ExecutionPolicy Bypass -File .\deploy\install-offsite-backup-task.ps1
```

## 手动运行与检查

```powershell
powershell -ExecutionPolicy Bypass -File D:\VeriWorkOffsiteBackups\offsite-backup-pull.ps1
Get-ChildItem D:\VeriWorkOffsiteBackups
Get-Content D:\VeriWorkOffsiteBackups\offsite-backup.log -Tail 20
```

## 恢复演练

1. 复制数据库备份到临时目录
2. 执行 `PRAGMA integrity_check;`
3. 解压证据包并检查 `manifest.json`
4. 在测试环境启动一次服务
5. 记录恢复耗时

## 云备份

如需跨地域容灾，再接入 OSS/COS/S3 或 restic/rclone；需要对象存储 Bucket、访问密钥和加密口令。
