# 职安盾 VeriWork｜省赛提交冲刺清单

截至 2026-10-08，项目已完成可运行原型、80条开发回归集、40条冻结留出集、规则/LLM评测工具和答辩演示。以下内容按“提交前必须完成”和“可选增强”分级。

## 一、必须先完成

- [ ] 确认报名赛道和作品名称：职安盾 VeriWork。
- [ ] 补全团队成员、学校、指导教师和分工信息。
- [ ] 使用两个以上通用大模型运行 `tools/evaluate_llm.py`。
- [ ] 招募至少20名高校学生完成一次风险识别与证据整理测试。
- [ ] 邀请法律实务人员对规则、标签和引用进行抽样复核，记录复核范围。
- [ ] 为北京、上海、广东政策包填入官方来源、数值、生效日期和核验人。
- [ ] 录制3至5分钟稳定演示视频，不使用网络不稳定时的实时API。
- [ ] 准备系统截图、架构图、数据流程图和评测结果图。
- [ ] 填写《人工智能工具使用情况说明》，保留提示词和人工修改记录。
- [ ] 完成第三方素材、法规来源、字体、图标和数据来源清单。
- [ ] 检查所有用户材料的上传、保存、删除和脱敏路径。

## 二、五周工作计划

### 第1周：实验与素材

- 接入模型A和模型B，运行冻结留出集。
- 生成模型直答、普通RAG、职安盾混合链三组对照结果。
- 完成20名用户测试问卷和任务计时。
- 录制第一版演示视频，暴露交互问题。

### 第2周：政策与规则

- 完成地方政策核验，禁止使用无来源数字。
- 法律实务人员抽样复核30个以上案例。
- 对失败案例建立问题分类：规则漏检、语义歧义、知识过期、上下文不足。
- 修订用户协议、隐私说明和免责声明。

### 第3周：产品打磨

- 优化首页、研判页和评测页的演示路径。
- 增加异常提示、导出材料和无网络降级。
- 统一术语、图标、颜色和答辩截图。
- 完成PC与移动端实际浏览器测试。

### 第4周：答辩与视频

- 使用 `presentation.html` 完成10至13页答辩PPT。
- 将 `docs/三分钟演示脚本.md` 更新为最终实测数据。
- 录制3分钟版和5分钟版视频。
- 准备评委常见问题与回答证据。

### 第5周：提交前审计

- 全量回归测试。
- 检查文件名、格式、大小和提交清单。
- 再次核对日期、联系人、版权和AI使用声明。
- 至少提前24小时完成最终提交。

## 三、五名团队分工

1. 队长/产品：需求、进度、用户测试、最终提交。
2. 前端/交互：Web演示、答辩截图、可用性优化。
3. 后端/数据：服务、政策包、日志、隐私和部署。
4. 模型/评测：LLM对照、规则链、指标与失败案例。
5. 设计/材料：PPT、视频、视觉、法规来源和AI使用说明。

## 四、答辩必须说清的四件事

1. 为什么通用大模型直接回答不可信。
2. 规则、检索、大模型和校验器各负责什么。
3. 当前哪些数据是合成数据，哪些结果已经实际运行。
4. 哪些问题仍需要人工核验，不能夸大为法律结论。

## 五、严禁出现的表述

- “系统准确率100%”且不说明数据集性质。
- “大模型判断完全可靠”。
- “可以替代律师或仲裁机构”。
- “已经服务大量真实用户”但没有授权和统计依据。
- 使用未经核验的地方最低工资数字。
- 把模型生成内容全部写成团队原创，不披露AI使用。
