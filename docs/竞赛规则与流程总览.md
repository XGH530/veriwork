# 2026年数媒竞赛｜规则、流程与团队执行总览

> 依据用户提供的《关于举办2026年第十四届全国大学生数字媒体科技作品及创意竞赛的通知》和附件1《2026年第十四届全国大学生数字媒体科技作品及创意竞赛参赛指南》整理。若官网后续发布更新，以官网和《作品材料提交规范》《评分标准及奖项设置》等配套文件为准。

## 一、竞赛是什么

- 全称：全国大学生数字媒体科技作品及创意竞赛，简称“数媒竞赛”。
- 举办届次：2026年第十四届。
- 参赛对象：普通高校全日制在校研究生、本科生和高职高专学生，专业不限。
- 赛事性质：数字媒体、人工智能、虚拟现实、游戏、数字艺术、移动应用、网络系统等方向的科技与创意实践竞赛。
- 赛制：校级初赛、赛区选拔赛、全国总决赛三级赛制。
- 官网：www.cmit.cn
- 官方邮箱：mail@cmit.cn

## 二、你们选择的具体赛道

职安盾应申报：

> 自主选题类—移动与网络应用开发类赛项

原因：该赛项面向移动端、Web端、小程序和网络信息系统，包含“移动应用、Web应用和微信小程序”“信息系统、智能服务平台和算法应用”“校园、社会及行业服务应用”三个方向。

职安盾的核心成果是 Web/移动端可信就业风险系统，属于“信息系统、智能服务、社会服务应用”，因此可以归入该赛项。

## 三、完整赛道体系

### 1. 指定命题类，共7个

1. “科幻+及元宇宙数字作品”数字作品。
2. AIGC类数字创意作品创作。
3. “红色之旅 追梦铸魂”作品。
4. “乡村振兴 科创赋能”作品。
5. “民族文化创新表达”作品。
6. “科技+创意，讲好中国故事”作品。
7. “虚幻引擎（UE）作品创作”作品。

指定命题按照各专项赛道公布的赛题参加。

### 2. 自主选题类，共8个

1. 虚拟现实（VR/AR/MR/XR）与游戏类。
2. 移动与网络应用开发类。
3. 影视与动漫创作类。
4. 数字艺术与可视化设计类。
5. 智能产品与硬件创意类。
6. 人居环境与空间设计类。
7. 智慧教育与科普创作类。
8. 其他创新作品类。

赛道选择原则：作品直接响应指定命题时优先报指定命题；否则根据作品主要目标、核心功能和最终成果形态选择自主选题。跨类别作品选择最能体现核心创新和主要工作量的赛项。

## 四、谁可以参赛

1. 普通高校全日制在校研究生、本科生和高职高专学生均可参加。
2. 来华留学生、港澳台高校学生和境外高校学生可参加国际作品赛道。
3. 毕业未满五年的创业团队只能参加经主办方批准且在指南中明确开放的指定命题，并提交学历、毕业时间、团队身份材料。
4. 作品应由学生团队独立完成。指导教师可以指导选题、技术路线、创作方法、过程管理和材料规范，但不能代替学生完成核心创作、系统开发、作品说明和答辩。

## 五、团队规则

1. 每个团队学生不超过5人。
2. 设团队负责人1名。
3. 可设指导教师1至2名。
4. 指导教师应为团队成员所在高校在职教师。
5. 研究生以学生身份参赛时，不能再作为指导教师。
6. 允许跨学科、跨专业、跨年级和跨学校组队。
7. 跨校团队必须确定第一申报单位和团队负责人，由第一申报单位负责资格审核、校内推荐和信息确认。
8. 报名截止后原则上不得变更申报单位、成员和指导教师。确属录入错误的，必须按期限提交书面审核程序并由单位盖章确认。

## 六、报名和提交规则

1. 团队负责人通过竞赛官网完成注册、报名和材料提交。
2. 报名信息必须真实、准确、完整。
3. 同一件作品只能选择一个赛道类型和对应赛项，不得重复申报或实质相同多头申报。
4. 系统显示“提交成功”并生成作品编号后，才算完成报名。
5. 只保存草稿、材料未上传完成或未最终提交，不进入审核和评审。
6. 报名及作品提交截止时间：2026年10月23日23:59:59。
7. 系统开放期间可以更新材料，以截止前最后一次成功提交版本为准。
8. 作品编号、团队信息和获奖证书信息以报名截止时系统确认的信息为准。

## 七、基本申报材料

根据指南，以下为基本申报材料：

1. 作品介绍文档。
2. 演示视频。
3. 原创性与知识产权声明。
4. 人工智能工具使用情况说明。
5. 其他成果形态材料按《作品材料提交规范》提交。

移动与网络应用赛项另行要求：

1. 可访问或可运行版本。
2. 系统说明。
3. 功能演示。
4. 界面截图。
5. 技术架构和测试说明。
6. 涉及用户信息、网络通信、数据存储和算法时，需要体现数据安全、隐私保护和合规意识。

## 九、学校审核与赛区晋级

1. 参赛高校负责本校作品的资格、内容导向、原创性、知识产权和材料完整性审核。
2. 推荐作品应进行校内公示。
3. 校赛推荐数量不超过本校资格审核通过作品数量的40%。40%是上限，不是必须达到。
4. 未达到质量要求的作品可以不推荐。
5. 赛区组织分类评审、公示和材料复核，按统一规则推荐全国总决赛。
6. 全国总决赛入围以官网公布名单为准。

## 十、评审规则

1. 竞赛采用百分制和分类评价。
2. 校级初赛和赛区选拔赛主要依据参赛材料进行评审。
3. 全国总决赛原则上采用作品展示、现场演示、专家评审和答辩交流相结合的方式。
4. 校赛评审组原则上不少于3人且为奇数。
5. 赛区评审组原则上不少于3人且为奇数，兼顾高校和产业专家。
6. 全国总决赛每组由3名来自不同单位的产业或行业专家组成。
7. 全国总决赛采用独立评分、现场问答和集体复核。
8. 专家执行保密、廉洁和回避制度。
9. 具体分值、评分指标、同分处理、晋级比例和奖项比例，以《评分标准及奖项设置》为准；该文件不在当前附件1中，必须从官网下载并核对。

## 十一、奖项设置

只有两个奖项层级：

1. 赛区选拔赛奖项。
2. 全国总决赛奖项。

每个层级只设置一等奖、二等奖和三等奖。各等级比例为最高控制比例，不是必须达到；未达到质量标准的奖项可以空缺。校级初赛不另设上述一二三等奖，只负责审核和推荐。

## 十二、人工智能使用规则

1. 必须填写统一《人工智能工具使用情况说明》，勾选“使用”或“未使用”。
2. 使用AI时，应填写工具名称、使用环节、主要工作流、人工筛选修改、团队原创贡献、版权和数据合规情况。
3. 生成或合成内容应按国家规定进行标识。
4. 使用AI本身不是简单加分或扣分项，评审重点是原创构思、团队实质性贡献和人机协同质量。
5. 未如实披露AI使用、无法说明作品形成过程或明显缺少学生团队实质贡献，会按参赛纪律处理。

职安盾使用了规则开发、代码生成、文档撰写和潜在大模型调用，必须如实填写。不能把系统开发全部写成团队原创，也不能把AI生成的代码和材料直接冒充个人原创。

## 十三、知识产权与纪律

1. 作品必须原创，不得抄袭、剽窃、套作、冒名或虚假申报。
2. 第三方素材、数据、模型、软件、字体、音乐、图像、视频和代码应合法使用并注明来源。
3. 往届相同或实质相同作品不得重复参赛。
4. 往届作品进行实质性改进的，应说明原有成果、新增内容和本届团队贡献。
5. 已公开、试用或处于成果转化阶段不当然禁止参赛，但不得隐瞒权属、既有成果和合作情况。
6. 存在知识产权争议或重大法律风险，可能被取消参评资格。

2. 产品/前端：界面、交互、演示流程、截图。
3. 后端/数据：服务端、隐私、数据存储、材料提交。

5. 设计/材料：PPT、视频、AI使用说明、知识产权和来源清单。
