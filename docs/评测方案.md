# 职安盾 VeriWork｜评测方案 V2

## 1. 评测目标

比较三类系统，回答“高后果就业合同场景中，怎样的 AI 系统才更可信”：

1. 通用大模型直接回答。
2. 通用大模型 + 普通 RAG。
3. 职安盾混合链：确定性规则 + 语义回退 + 法源检索 + 大模型 + 拒答与校验。

本项目不以“模型看起来回答得完整”为成功标准，而以风险召回、法源可追溯、错误引用和待核实能力为核心。

## 2. 数据分层

| 数据集 | 数量 | 用途 | 使用限制 |
|---|---:|---|---|
| 开发回归集 V1 | 80 | 规则开发、功能回归、消融 | 已参与开发，不能作为独立盲测 |
| 早期留出集 V1 | 32 | 发现关键词泛化问题 | 暴露问题后用于一次规则强化 |
| 冻结留出集 V2 | 40 | 报告混合规则链泛化差距 | 创建后不再根据该结果调规则 |
| 真实用户测试 | 目标20+ | 检验真实使用效率 | 必须获得授权并去标识化 |

当前所有外部评测样本均为团队合成文本，不含真实个人信息。

## 3. 标注对象

每条样本至少包含：

- 期望风险 ID。
- 难度：简单、中等、困难。
- 是否信息不足并应拒答。
- 来源类型和个人信息标记。
- 复核状态。
- 备注与失败原因。

## 4. 指标

- 风险精确率 Precision。
- 风险召回率 Recall。
- 风险 F1。
- 样本完全匹配率。
- 法源覆盖率。
- 待核实召回率。
- 应待核实却输出确定结论的比例。
- 平均响应时间。
- 用户完成风险识别和证据整理的用时变化。

## 5. 已完成结果

### 开发回归集

- 40条测试划分上，规则+语义链 F1 为 100%。
- 全量80条上，需要以 `results/rules_v1_report.md` 的最新结果为准。
- 该结果只能说明开发集回归，不代表真实泛化。

### 冻结留出集 V2

- 纯规则+语义回退链 Precision 100%，Recall 26.9%，F1 42.4%。
- 结果表明：固定规则对已知表达可控，但对开放语言的长尾表述明显不足。
- 该结果被保留，不用继续调规则刷高，作为大模型层必要性的证据。

## 6. 下一步模型实验

分别运行至少两个通用模型：

```bash
python tools/evaluate_llm.py \
  --dataset data/holdout_cases_v2_frozen.json \
  --model model-a \
  --api-url https://provider-a/v1/chat/completions \
  --api-key-env LLM_API_KEY \
  --output-prefix model_a_holdout_v2

python tools/evaluate_llm.py \
  --dataset data/holdout_cases_v2_frozen.json \
  --model model-b \
  --api-url https://provider-b/v1/chat/completions \
  --api-key-env LLM_API_KEY \
  --output-prefix model_b_holdout_v2
```

再使用 `--model-only` 运行纯模型基线，比较：

- 模型直答。
- 模型 + 职安盾规则链。
- 普通模型 + 法源 RAG。
- 职安盾完整混合链。

## 7. 用户测试

至少招募20名高校学生。每个人完成：

1. 阅读一份含风险条款的合同。
2. 记录自己识别出的风险。
3. 使用职安盾完成研判。
4. 根据系统结果整理证据与沟通问题。
5. 填写隐私、可信度、易用性和行动清晰度问卷。

记录使用前后用时、漏检项、误判项和系统建议采纳情况。

## 8. 外部复核

邀请法律实务人员对规则和标签抽样复核，但必须准确记录：

- 复核样本数量。
- 复核人身份和资格范围。
- 修改意见及采纳情况。
- 未复核范围。

不得把个人抽样复核扩大表述为“权威机构认证”。

## 9. 消融实验

分别移除：

- 规则引擎。
- 法源检索。
- 拒答机制。
- 模型解释层。
- 语义回退层。

重点观察高后果错误，而不是只看平均分。

## 10. 失败案例

必须保留：

- 规则关键词误报。
- 语义层漏掉的口语和新词表达。
- 地方政策版本错误。
- 劳动关系认定错误。
- 模型引用不存在的法条。
- 信息不足却输出确定结论。

失败案例进入 `results/` 和答辩材料，不通过删除失败结果来制造“完美指标”。

## 11. 结果呈现

答辩中区分三类陈述：

- **已实测**：可以直接展示数据来源和脚本结果。
- **开发集回归**：明确说明样本参与开发。
- **待完成**：模型对照、真实用户测试和外部复核。

任何结果都必须给出数据集版本、系统版本、模型版本、提示词策略和运行日期。
