# 职安盾用户测试与法律复核方案

## 1. 目标

用真实用户和外部专业意见验证系统，而不是只展示团队自测成功案例。

最低闭环：

- 20 名目标用户完成有任务说明的试用
- 10 份合同由法律实务人员抽样复核
- 至少保留 5 个失败案例和对应修正记录
- 冻结一套不参与调规则的留出集
- 形成“改进前 / 改进后”对照表

## 2. 用户样本

建议覆盖：

| 用户类型 | 人数 | 典型任务 |
| --- | --- | --- |
| 应届本科生 | 8 | 识别试用期、违约金、押金风险 |
| 高职高专学生 | 4 | 实习协议、收费和培训贷风险 |
| 研究生 | 4 | 竞业、知识产权、保密条款 |
| 毕业 1—3 年职场人 | 4 | 工资、社保、加班与离职限制 |

## 3. 测试任务

每名用户在不接受提示的情况下完成：

1. 上传或粘贴一份脱敏合同
2. 找出至少 3 个高风险条款
3. 核对每条风险的原文、法源和行动建议
4. 上传 1 个模拟证据文件
5. 生成研判报告
6. 下载证据包
7. 填写 SUS 或 5 级满意度问卷

记录：

- 完成时间
- 任务成功/失败
- 哪一步卡住
- 是否理解“待核实”
- 是否误把系统结论当成正式法律意见
- 是否愿意继续使用

## 4. 法律复核抽样

由指导教师协助联系律师、企业法务、劳动仲裁或人社工作人员，至少复核 10 份合同。

抽样应覆盖：

- 试用期与工资
- 社保与公积金
- 押金、培训贷、设备费
- 竞业限制
- 加班与休假
- 违约金
- 劳务/实习/劳动关系的边界

复核表字段：

| 字段 | 说明 |
| --- | --- |
| 案例编号 | 不含真实姓名 |
| 系统结论 | 风险项、等级、法源 |
| 专家结论 | 同意 / 部分同意 / 不同意 |
| 差异原因 | 规则、事实缺失、法源错误或表达问题 |
| 修正动作 | 需修改的规则、提示词或页面 |
| 复核人类型 | 律师 / 法务 / 仲裁 / 人社 / 教师 |
| 复核日期 | YYYY-MM-DD |

## 5. 指标

至少报告：

- 高风险条款召回率
- 风险结论精确率
- 法源覆盖率
- 无依据结论率
- 待核实召回率
- 平均完成时间
- 用户任务成功率
- 法律复核一致率
- 严重错误数量

严重错误定义：

- 把明显高风险条款判为无风险
- 引用错误法条却给出确定性结论
- 在信息不足时不提示人工核实
- 泄露用户原文或个人信息

## 6. 隐私与授权

- 真实合同必须取得使用者书面授权
- 入库前删除姓名、电话、身份证、地址、公司敏感信息
- 公开材料只展示脱敏片段
- 测试结束后按约定删除原始材料
- 记录数据处理目的、保存期限和删除时间

## 7. 国奖答辩可展示材料

- 20 人测试样本结构
- 任务成功率和平均完成时间
- 法律复核一致率与差异案例
- 改进前后对照
- 失败案例和修正记录
- 用户访谈原话（匿名）
- 冻结留出集结果
