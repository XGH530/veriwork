# 平台后台与数据治理说明

## 账号与会话

- 普通用户可注册、修改密码、查看登录设备、退出其他设备
- 支持邮箱绑定、邮箱验证码找回密码
- 管理员可停用/启用、重置密码、调整角色和删除用户
- 管理员邮箱二次验证已实现，配置 SMTP 授权码后将 `ADMIN_2FA_ENABLED` 设为 `1` 即可启用
- 修改密码和管理员重置密码会注销该用户全部旧会话
- 被停用用户的现有会话立即失效

## 案例档案

- 每次登录后的研判自动保存脱敏快照
- 原始合同文本不进入案例库
- 手机号、身份证号、邮箱和银行卡号入库前脱敏
- 状态支持：进行中、跟进中、已处理、已归档
- 用户可删除案例，关联证据文件同步删除

## 证据文件

- 支持 PDF、Word、图片、TXT、邮件文件
- 单文件默认不超过 8MB
- 校验扩展名与文件签名
- 保存到 `/opt/veriwork-data/evidence`
- 保存 SHA-256、大小、类型、上传时间和关联案例
- 每个文件写入 HMAC 链式记录，记录前序哈希和当前记录哈希
- 上传、下载、删除写入保管事件
- 支持证据链完整性校验、单文件下载和 ZIP 证据包下载
- ZIP 内包含 `manifest.json`、链式校验结果和全部原件

## 报告

- 案例详情可直接下载服务端生成的 PDF 报告
- 未安装 PDF 组件时自动退回 A4 打印版，浏览器可另存为 PDF
- 报告包含风险结论、原文片段、法源、轨迹、证据哈希和后续行动
- 报告不包含未脱敏个人信息

## 审计日志

记录登录、研判、上传、下载、删除、导出、改密、管理员操作等事件，保留操作者、对象、时间、IP 和简短说明。

审计日志不记录合同原文、密码、Cookie 或 API Key。

## 数据删除

- 用户删除账号：删除案例、证据、会话和账户记录
- 管理员删除用户：执行同样的数据清理
- 审计日志保留必要的最小操作记录，不保留被删除用户的内容数据
