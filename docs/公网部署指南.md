# 公网部署说明

项目使用Python标准库提供服务，不依赖第三方运行库。可以把整个目录部署到支持Python的PaaS平台。

## 部署前

1. 不要上传 `.env`、API密钥和真实用户材料。
2. 确认服务器允许绑定 `0.0.0.0`。
3. 在平台环境变量中配置：
   - `HOST=0.0.0.0`
   - `PORT=平台提供的端口`
   - `LLM_API_URL`
   - `LLM_API_KEY`
   - `LLM_MODEL`
4. 正式公网部署应在前面增加HTTPS反向代理和访问日志。

## Render示例

仓库根目录已经包含 `render.yaml`。在Render中创建Blueprint并连接仓库后，平台会读取配置。API密钥必须使用平台环境变量，不要写入仓库。

## Railway或其他PaaS

构建命令留空，启动命令使用：

```bash
python server.py
```

平台会自动提供 `PORT` 环境变量。

## Docker

```bash
docker build -t veriwork .
docker run --rm -p 8000:8000 --env-file .env veriwork
```

访问 `http://127.0.0.1:8000`。

## 公网演示前检查

- API密钥未进入浏览器或压缩包；
- 上传体和请求频率有限制；
- 没有真实个人信息；
- 演示数据与生产数据分离；
- 有基本隐私说明；
- 不把系统描述为法律意见服务。
