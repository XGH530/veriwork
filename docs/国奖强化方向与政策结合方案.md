# 职安盾国奖强化方向与政策结合方案

## 一、赛道确认

职安盾当前应申报：

> 自主选题类—移动与网络应用开发类赛项

不是AIGC内容赛道，也不是红色文化、乡村振兴或民族文化指定命题。作品主体是面向就业服务的网络信息系统。

## 二、国奖竞争现实

2025年国赛移动应用开发与微信小程序相关获奖作品约339项，其中一等奖28项。国奖一等奖通常不是单一工具，而是：

- 有清晰用户和真实场景；
- 有可持续使用的产品形态；
- 有算法、数据、平台或硬件亮点；
- 有学校、企业、医院、政府部门或机构合作；
- 有用户使用结果和社会价值。

职安盾现在的优势是可信AI、规则、法源和证据链，缺点是缺少真实用户和外部落地。

## 三、建议的国奖定位

将职安盾从“合同风险检查工具”升级为：

> 面向高校毕业生和新就业形态劳动者的就业权益与政策直达平台

形成三段式闭环：

1. 签约前：核查就业合同、实习协议和招聘信息风险。
2. 入职后：匹配国家、省、市就业扶持政策，生成申领材料清单。
3. 发生纠纷：整理证据链、沟通问题和维权材料。

答辩一句话：

> 让毕业生在签约前、入职后和发生纠纷三个阶段，都能获得有依据、可核验、可行动的就业服务。

## 四、国家政策结合方向

可以对接以下政策方向，正式参赛以最新官方文件为准：

- 就业优先战略和高质量充分就业；
- 高校毕业生等青年就业创业促进工作；
- 公共就业服务专项行动；
- “人工智能+”在公共服务中的应用；
- 灵活就业和新就业形态劳动者权益保障；
- 职业技能培训、就业见习和社会保险补贴；
- 创业担保贷款和一次性创业扶持；
- 基层就业、学费补偿和助学贷款代偿；
- 公共法律服务和劳动权益法律援助。

## 五、别人没有的四件东西

### 1. 就业政策适配引擎

根据用户的身份、地区、就业状态和需求，匹配适用政策。

输出内容必须包括：

- 政策名称；
- 适用对象；
- 申请条件；
- 补贴或支持内容；
- 所需材料；
- 申领渠道；
- 生效时间；
- 官方来源链接；
- 仍待核验事项。

不是普通政策搜索，而是“用户条件到政策条件”的结构化匹配。

### 2. 就业风险可信AI评测基准

建立一套公开、可复现的劳动权益风险评测集，包含：

- 真实语法变化；
- 否定表达；
- 社保和试用期边界；
- 实习、兼职和灵活就业；
- 信息不足需要拒答；
- 通用模型错误引用。

目前已经完成80条开发集、32条早期留出集、40条冻结留出集，并且完成两个DeepSeek模型公平对照，这是其他学生作品通常没有的研究部分。

### 3. 可信证据链

不要只做证据复选框，应增加：

- 用户上传证据文件；
- 文件哈希；
- 上传时间戳；
- 证据分类；
- 事件时间线；
- 证据完整度评分；
- 导出证据目录。

### 4. 模型受限决策机制

清楚说明：

- 规则拥有硬约束权；
- 模型只提出有原文依据的候选；
- 无法引用法源时拒答；
- 地方政策需记录版本和生效日期；
- 所有结论可追溯和人工复核。

这比单纯说“使用大模型”更符合国家AI治理和可信AI方向。

## 六、建议新增的产品页面

新增一个“政策服务”一级导航，包含：

1. 政策匹配问卷；
2. 匹配结果；
3. 申领材料清单；
4. 政策原文和版本；
5. 地区政策比较；
6. 收藏和办理进度。

用户身份可以包括：

- 在校生；
- 应届毕业生；
- 毕业两年内未就业青年；
- 灵活就业人员；
- 创业者；
- 就业困难人员；
- 新就业形态劳动者。

## 七、八天强化顺序

### 第1天

- 抓取国家层面就业政策原文；
- 建立政策字段结构；
- 确定10至15项核心政策。

### 第2天

- 抓取北京、上海、广东代表性地方政策；
- 记录生效日期和来源；
- 建立地区适配规则。

### 第3天

- 开发“政策服务”页面；
- 完成条件问卷和政策匹配；
- 生成申领材料清单。

### 第4天

- 接入现有合同风险与证据链；
- 形成“风险—政策—证据”闭环；
- 完成20名用户测试。

### 第5天

- 法律与就业服务人员抽样复核；
- 修正政策条件和风险边界；
- 补充失败案例。

### 第6天

- 更新系统说明、作品介绍和AI使用说明；
- 增加政策数据来源清单；
- 录制新演示视频。

### 第7天

- 完成品牌版PPT和答辩问答；
- 进行完整彩排。

### 第8天

- 提交学校审核；
- 不再增加功能。

## 八、答辩必须回答的问题

### 为什么不是普通政策搜索？

因为职安盾把用户条件、政策条件、合同风险和证据材料放在同一条流程中，不是只展示政策列表。

### 为什么不是普通法律聊天？

因为硬规则、法源、模型候选和校验器分工明确，模型不能改写规则，也不能凭空新增法条。

### 为什么有国家政策价值？

因为它服务于高校毕业生就业、公共就业服务、劳动者权益保障和数字政府建设，可以接入高校就业中心和公共就业服务平台。

### 别人为什么不容易复制？

因为他们需要同时具备：

- 劳动风险规则；
- 公开政策版本治理；
- 可信模型评测；
- 证据链；
- 产品化前端；
- 高校和就业服务场景。

## 九、最大的风险

1. 地方政策适用条件不能猜。
2. 政策金额和截止时间必须记录官方来源。
3. 不能承诺自动申领或必定符合条件。
4. 不能把系统说成律师或政府官方平台。
5. 必须明确数据脱敏、用户授权和保存期限。

## 十、最终建议

在当前项目基础上增加“政策服务”模块，比重新换题更现实。国奖叙事改为：

> 职安盾不是法律问答工具，而是面向高校毕业生和新就业形态劳动者的可信就业服务基础设施。它把就业合同风险、国家扶持政策和可信证据链连接起来，帮助用户从发现问题走到获得服务和维护权益。

如果要在国奖中形成明显差异，最有价值的新增项按顺序是：

1. 就业政策适配引擎；
2. 可信证据链文件上传；
3. 就业风险AI评测基准公开报告；
4. 高校就业中心试用证明；
5. 政策版本和来源治理。
